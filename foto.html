Cara tambah foto baru

  1. Login cloudinary.com → Media Library → Upload foto
  2. Klik foto yang diupload → salin Public ID-nya (contoh: pitamaha5/foto-lantai-1)
  3. Buka foto.html → cari const photos = [ → tambahkan baris baru sesuai contoh
  4. Commit & Push via GitHub Desktop — foto langsung tampil

Cara tambah video baru

  1. Upload video ke YouTube → saat upload pilih visibilitas "Unlisted" (tidak muncul di pencarian)
  2. Salin link video, ambil ID-nya: youtube.com/watch?v=[ID INI]
  3. Buka foto.html → cari const videos = [ → tambahkan baris baru sesuai contoh
  4. Commit & Push via GitHub Desktop — video langsung tampil
